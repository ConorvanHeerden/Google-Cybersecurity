# Google Cybersecurity

Each file represents a modules worth of assignments. The assignments are based on the ones provided, but I commonly found the level of

complexity of the original ones disappointing, so I changed the requirements slightly.



This assignments generally have more of a generic, neutral approach to cybersecurity instead of focusing on one field. 

While the Google cybersecurity course generally leans towards SOC, it is meant for beginners.
